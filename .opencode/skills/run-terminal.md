# Run RPG Terminal (Modo Terminal)

Ejecuta el juego en la terminal con menús interactivos.

## Comandos
```bash
# Compilar y ejecutar
npm run dev

# O si ya está compilado
npm start
```

## Navegación
- Usa las flechas del teclado para moverte por los menús
- Enter para seleccionar
- Los combates muestran stats en tiempo real con barras de HP/MP
- Las decisiones se toman con menús interactivos: Atacar, Habilidad, Objeto, Defender

## Solución de Problemas
- Si el menú no se renderiza bien, asegúrate de que la terminal soporte colores ANSI y Unicode
- En Windows, usar Windows Terminal o PowerShell 7+ para mejor experiencia
